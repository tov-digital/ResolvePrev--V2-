# StatTile

Bloco de dado curto, com rótulo pequeno e valor maior, em fundo suave; o tom `danger` destaca o dado que pede atenção.

## Regras de uso

- Para dados de perfil e contagens rápidas (idade, aniversário, totais).
- `danger-soft` só para o dado que muda a decisão (ex.: um impedimento); no máximo um por grupo.
- `brand` para o dado-chave positivo; `success` para metas batidas.
