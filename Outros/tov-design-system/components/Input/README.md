# Input

Campo de texto com rótulo, dica e estado de erro, com borda visível e cantos de 12px.

## Regras de uso

- Rótulo sempre visível acima do campo; o placeholder é só exemplo, nunca o rótulo.
- Borda `line-strong` (3:1). Em foco, anel `focus` de 2px.
- Erro: borda e mensagem em `danger`, com texto que diz como corrigir.
