# Icon

Ícones de traço (1,8px, pontas arredondadas) em grade de 24px, que herdam a cor do texto.

## Regras de uso

- Tamanhos: 16px em abas e selos, 18px em botões, 20px na navegação.
- Sempre ao lado de um texto ou com `aria-label` no botão que o contém.
- Disponíveis: dashboard, users, money, calendar, message, file, folder, filter, plus, close, check, chevron, logout, search.
