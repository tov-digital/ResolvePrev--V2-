# Button

Botão de ação com cinco variantes; o preto Tov (primary) é o padrão e o amarelo (brand) fica reservado para a ação de maior destaque da tela.

## Regras de uso

- **primary** (preto): a ação principal de um bloco. No máximo um por área.
- **brand** (amarelo): a ação mais importante da tela inteira, como “Agendar reunião”. Use com moderação, como o ponto da marca.
- **secondary**: ações de apoio ao lado da principal (“Enviar mensagem”).
- **ghost**: ações discretas em barras de ferramentas e cabeçalhos.
- **danger**: excluir, cancelar, recusar.
- Altura mínima de 44px (36px no tamanho `sm`). Botão só com ícone exige `aria-label`.
- Texto no infinitivo e curto: “Salvar”, “Agendar reunião”.
