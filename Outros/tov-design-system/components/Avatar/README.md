# Avatar

Círculo com foto ou iniciais da pessoa, em amarelo suave por padrão ou em preto.

## Regras de uso

- Use as iniciais (até duas letras) quando não houver foto.
- Tamanhos: 24px em listas densas, 32–40px em cabeçalhos e chips, 56px em perfis.
- `tone="dark"` para o usuário logado ou administradores, distinguindo de clientes.
