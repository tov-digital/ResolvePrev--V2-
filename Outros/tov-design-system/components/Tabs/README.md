# Tabs

Abas de texto com sublinhado amarelo na aba ativa, para alternar visões dentro de um cartão ou modal.

## Regras de uso

- Use de 2 a 5 abas, com rótulos curtos e um ícone opcional.
- A aba ativa fica em `ink` com uma barra `brand` de 3px; as outras ficam em `ink-muted`.
- As abas trocam o conteúdo do mesmo contexto. Para mudar de página, use `NavItem`.
