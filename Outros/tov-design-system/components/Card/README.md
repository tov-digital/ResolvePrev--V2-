# Card

Cartão branco de cantos bem arredondados (24px) sobre o fundo cinza claro; é a unidade básica de toda tela.

## Regras de uso

- Sempre sobre `bg`. Borda `line` de 1px e sombra `shadow-card` quase imperceptível: o contraste vem do fundo, não da sombra.
- Padding de 24px (`space-6`); 32px em cartões grandes.
- Título em `h3` (Montserrat), descrição em `ink-muted`. Ações no canto superior direito.
- Blocos internos (linhas, tiles) usam `surface-muted` com `radius-lg`, nunca outro cartão com sombra.
