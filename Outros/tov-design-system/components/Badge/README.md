# Badge

Selo em pílula para status, etapa e categoria, com tons suaves; a variante `code` vira o selo quadrado de sigla usado nas linhas de indicador.

## Regras de uso

- Tons suaves (`*-soft` de fundo + cor cheia no texto) para não competir com o conteúdo.
- `dot` adiciona um ponto de status, ecoando o ponto da marca.
- `brand` (amarelo suave) para destaque de marca; `solid` (preto) para rótulos de sistema como “PAINEL ADMIN”.
- `code` mostra siglas curtas (2–3 letras) em selo quadrado, com a mesma cor da barra que acompanha.
- Sempre texto, nunca só cor: o significado precisa estar escrito.
