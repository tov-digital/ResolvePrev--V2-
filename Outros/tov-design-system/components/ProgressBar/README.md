# ProgressBar

Barra de progresso em pílula, amarela por padrão, com trilho suave.

## Regras de uso

- 12px de altura, cantos em pílula e trilho `surface-hover`.
- Amarelo (`brand`) como padrão. Use outros tons só quando as barras representam categorias diferentes, como as etapas de um funil.
- Sempre acompanhada do número escrito, porque a barra sozinha não informa o valor.
