# Logos

Arquivos oficiais da marca Tov, em PNG com fundo transparente, exceto o favicon.

| Arquivo | Uso |
| --- | --- |
| `tov-negativa.png` | Versão principal: "tov" branco com ponto amarelo, sobre `primary` ou fundos escuros. |
| `tov-positiva.png` | "tov" preto com ponto amarelo, sobre `surface` e `bg` (sidebar, cabeçalhos claros). |
| `tov-mono-branca.png` | Tudo branco, sobre fotos e fundos escuros coloridos. |
| `tov-mono-preta.png` | Tudo preto, sobre `brand` (amarelo) e em impressão de uma cor. |
| `simbolo-favicon.png` | Símbolo "t." em quadrado preto: favicon, avatar e ícone de app. |
| `simbolo-positivo.png` | Símbolo "t." preto com ponto amarelo, sem fundo. |

Não redesenhe a logo nem a recrie com texto. Regras completas no Manual de Identidade Visual da Tov.
